# Architecture diagrams

The Mermaid sources in this directory are the editable, version-controlled diagrams used by the
portfolio documentation:

- `architecture.mmd` shows deployed process and data boundaries.
- `ai-scoring-flow.mmd` shows deterministic and optional model-backed scoring behavior.
- `agent-workflow.mmd` shows development-time agent orchestration, not product runtime behavior.

GitHub renders equivalent Mermaid blocks in the README and supporting documents. Update the source
files and the embedded copy together when architecture changes.
