# Changelog

All notable project changes will be recorded here. The project currently uses milestone-based
entries rather than semantic-version releases.

## Unreleased

- Reframed the repository around a verifiable portfolio narrative.
- Added implementation traceability, architecture diagrams, contribution and security guidance,
  versioned evaluation evidence, and a single local verification command.
- Documented the development-agent workflow separately from runtime product behavior.

## MVP vertical slice

- Added organization-scoped authentication, profiles, document processing, reviews, matching,
  compliance workflows, alerts, notifications, and amendment acknowledgements.
- Added SAM.gov synchronization and organization-owned attachment analysis.
- Added optional local Ollama scoring, cached embeddings, pgvector retrieval, deterministic
  fallbacks, and reproducible quality gates.
